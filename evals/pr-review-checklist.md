# PR Review Eval Checklist

## 목적

PR을 열기 전 AI가 스스로 리뷰해야 할 기준이다. 이 문서는 사람 리뷰어가 볼 수 없는 실행 흐름,
계약 불일치, 문서 누락을 잡는 데 집중한다.

## 리뷰 질문

- 요청한 문제를 실제로 해결했는가?
- 현재 구현과 향후 목표를 섞어 깨지는 변경을 만들지 않았는가?
- FE와 BE의 DTO, URL, 인증 헤더가 일치하는가?
- Controller, Service, Repository 책임이 섞이지 않았는가?
- 권한과 소유권 검사가 빠지지 않았는가?
- 실패 경로와 예외 응답이 검증되었는가?
- MySQL, Redis, S3 영향이 문서화되었는가?
- 커밋이 요구사항 단위로 분리되었는가?
- PR 본문에 다음 작업과 잔여 위험이 있는가?

## 결과 형식

```md
## 자체 리뷰 결과
- 통과:
- 수정 필요:
- 미검증:

## 위험
- DB:
- API:
- 인증:
- FE 연동:
- 배포:
```
